# Efeitos sonoros (sintetizados com ffmpeg, sem direitos de terceiros)

| arquivo | uso | caráter |
|---|---|---|
| boom.wav | clímax (1–2 por vídeo) | sub-grave 90→32 Hz, ataque seco, cauda ~1,5 s |
| hit.wav | número importante | impacto grave curto (~0,4 s) |
| riser.wav | tensão antes do boom | ruído crescente 1,2 s |
| whoosh.wav | troca de batida | sopro 0,5 s |
| pop.wav | ícone/cartão surgindo | pop seco 0,15 s |
| tickroll.wav | contador subindo | cliques a cada 60 ms (cortado na duração do contador) |
| tick.wav | clique isolado | 50 ms |
